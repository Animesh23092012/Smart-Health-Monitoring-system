THE PROJECT

Technology that connects health.

The Smart Health Monitoring System is a student innovation project that explores how sensors, microcontrollers, communication technology and software can work together to create a connected health-monitoring platform.

The prototype is designed to collect sensor information, transmit it to a computer system, store readings and display them through a user-friendly dashboard.
